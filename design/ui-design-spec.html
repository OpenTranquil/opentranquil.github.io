TranquilOS UI 设计规范

Mono Purism · 极简单色 · 800×480 横屏 · 能力安全微内核 TranquilOS
所有 mockup 左暗右亮对比。给 AI 实现时按此规范。

① 实现指令（Prompt）

你正在为 TranquilOS（aarch64 能力安全微内核，C + LVGL）实现 UI。设计语言是「Mono Purism 极简单色」。

硬约束：
1. 屏幕 800×480 横屏。status bar 56px（顶），nav bar 72px（底），应用内容区 800×352。
2. 单色 + 一抹电蓝：亮主题 accent #2E5BFF，暗主题 accent #4D7AFF。禁止第二个彩色（success/warning 仅用于状态指示）。
3. 无阴影、无渐变。层级靠「bg→surface 底色差 + 1px 发丝线」。
4. 圆角统一 4px；toggle/进度条/滑块 track 用胶囊(pill)。
5. 字体：阿里巴巴普惠体（继承）；数字用 tabular-nums 等宽对齐。
6. 应用只画内容区 800×352（无 appbar/topbar——应用名在 status bar 显示，返回在 nav bar）。
7. 横屏：凡「分类+内容」的应用用左右分栏（左菜单~34% + 右内容），不要上下堆叠。
8. 这是重构 UI，不是重新设计功能——保留现有应用的所有功能/数据/逻辑，只换外观。

组件 token（mono_surface）：surface 底(#F5F5F5/#141414) + 1px line(#ECECEC/#1C1C1C) + 4px 圆角 + 无阴影。
主动作按钮：accent 填充 + 白字 + 4px。
列表行：[图标] 标题 ... 值/控件 ›，底部 1px 发丝线。
开关 toggle：关=line2，开=accent，pill。
