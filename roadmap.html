已完成

Shipped · 可在 QEMU / 真机运行

  • AArch64 异常模型 + MMU 虚拟内存（EL0–EL3）
  • SMP 抢占式调度器 per-CPU + 负载均衡，scontext/xcontext 分离
  • Capability 访问控制 CNode / VSpace / Endpoint / Timer / Futex / IRQ
  • 迁移线程同步 IPC + endpoint pool 弹性 IPC
  • upcall 机制 内核 → 用户态调用转发
  • SystemDaemon procmgr / memmgr / ipcmgr / virtmgr
  • EL2 Type-1 hypervisor stage-2 · vGIC · vTimer · vPMU
  • initcall 分级初始化 LV0–LV7
  • 可加载内核模块 CFS 调度类插件
  • 12 个框架服务 窗口 / 文件 / 网络 / 设备 / 应用 / 字体 / 音频等
  • 图形栈 + 14 款应用 LVGL · FreeType · PortableGL · 800×480
  • GN/Ninja + IDL 工具链 服务接口代码生成
  • 四平台启动 QemuVirt · Pi3B · Pi4B · CM4
