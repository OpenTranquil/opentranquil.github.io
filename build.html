烧录镜像。

写错目标盘会覆盖其他磁盘——每一步都先确认设备编号。

MACOS

diskutil + dd

插入 SD 卡或让 CM4 eMMC 进入 mass-storage 模式：

diskutil list
diskutil unmountDisk /dev/diskN
sudo dd if=tranquil-cm4.img \
  of=/dev/rdiskN bs=4m \
  status=progress conv=sync
sync && diskutil eject /dev/diskN
LINUX

lsblk + dd

写入整盘设备，不要写分区节点（如 sdX1）：

lsblk
sudo umount /dev/sdX*
sudo dd if=tranquil-cm4.img \
  of=/dev/sdX bs=4M \
  status=progress conv=fsync
sync
RPIBOOT

eMMC 直写

CM4 IO 底板设置 USB boot 跳线，USB slave 口连主机：

rpiboot

镜像分区与布局。

boot.img (64MB)
  offset 0      Bootloader    8MB
  offset 2048   DTB           8MB
  offset 4096   Hypervisor   16MB
  offset 8192   Kernel       16MB
  offset 12288  SystemDaemon  8MB
  offset 14336  Ramdisk cpio  8MB
vendor.img (32MB, ext2)
  bin/  driver daemons (.drv)
  etc/  drivers.json

system.img (128MB, ext2)
  zygote · framework services
  system UI · app ELFs

user.img (64MB, ext2)
  用户数据模板：示例音乐 · 图片
  游戏 · AI 配置
boot.img无分区表，按固定偏移装载（上表）
vendor / system / userext2 分区镜像（mke2fs + debugfs）
raw 磁盘镜像FAT32 boot + ext2 vendor + ext2 system + ext2 user 四分区，由 make_all_img.sh 组装
CM4 boot 分区树莓派固件 + boot.img + DTB

make_boot_img.sh 以 objcopy + dd 按上述偏移组装 boot.img；make_system_img.sh / make_user_img.sh 组装 ext2 分区镜像；make_all_img.sh 将四个分区写入 raw 磁盘镜像。

工具链。

TOOLCHAIN

交叉编译器

产物为 freestanding AArch64 二进制。从 newos.org/toolchains 下载并解压到仓库 toolchains/，默认 aarch64-elf（GCC 12.2.0）。

MACOS ONLY

e2fsprogs

system.img 为 ext2 镜像；macOS 组装依赖 Homebrew e2fsprogs，缺少时组装会失败。

brew install e2fsprogs

注意：每个新 shell 都要 source env_setup.sh；OS_BASE_DIR 固定为 ~/kernel，检出到其他路径时需修改。
