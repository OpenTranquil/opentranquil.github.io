EL1 微内核。

  • AArch64 异常模型（EL0–EL3）与 MMU 虚拟内存
  • SMP 多核：per-CPU 调度与负载均衡
  • 抢占式调度器：execute / schedule 上下文分离
  • Capability 访问控制：CNode、VSpace、Endpoint、Timer、Futex、IRQ 等
  • 迁移线程同步 IPC + 弹性 IPC（endpoint pool）
  • Fastcall & upcall：内核 ↔ 用户态双向调用转发
  • initcall 系统（LV0–LV7）有序启动初始化
  • 高精度定时器与计时（ARM Generic Timer）
  • IRQ 管理：GICv2 / GICv3
  • Futex 同步原语
  • 电源管理框架（PSCI）
  • 可加载内核模块：CFS 调度类插件
  • 性能追踪（perf / perfmgr）与 backtrace
  • Console 子系统：UART、VirtIO console

EL2 Type-1 虚拟化。

  • Type-1 hypervisor：stage-2 页表地址转换
  • VM / VCPU / PCPU 生命周期管理
  • VGIC、VTimer、VPMU 虚拟化
  • Hypcall 接口，为 guest 与 host 通信提供基础

核心系统服务。

procmgr

进程管理

进程 / 线程生命周期、ELF 装载、PID 查找。

memmgr

内存管理

buddy 物理页分配器、虚拟地址空间、SHM 共享内存。

ipcmgr

IPC 命名空间

endpoint / pool 创建、name service、capability 克隆。

virtmgr

虚拟机管理

VM 创建与生命周期管理。

独立框架服务。

devmgr

设备管理

驱动 daemon 注册表、按类 IPC 转发与外设管理。

fsmgr

文件系统

VFS 抽象：rootfs、ext2、FAT32、procfs、sysfs。

netmgr

网络协议栈

lwIP TCP/IP；mbedTLS 支持 HTTPS 场景。

windowmgr

窗口合成

窗口合成器与 surface 管理，800×480 系统画布。

appmgr

应用生命周期

应用注册表管理，按需启动应用进程。

mmimgr

多模态输入

键盘、指针等输入事件的统一管理与分发。

audiomgr

音频服务

音频输出管理（VirtIO sound）。

fontmgr

字体渲染

FreeType 字体光栅化与排版支持。

statemgr

状态存储

系统级 KV 状态管理服务。

timemgr

时间服务

计时、RTC 闹钟与 NTP 同步。

agentmgr

AI Agent 框架

面向 AI agent 的系统级服务框架。

imemgr

输入法

输入法编辑器（IME）服务。
