启动 virt 镜像。

01推荐：仓库脚本

完整设备参数、显示后端与调试选项都在 run_qemu_virt.sh 里维护，优先使用它启动。

02放置镜像

把下载的 tranquil-virt.img 放到内核仓库 out/ 目录下，脚本会直接复用。

03手写参数时

CPU、GIC、ramfb、VirtIO block/net/input/sound 与串口参数需与 QemuVirt 平台配置保持一致。

烧录到 Compute Module 4。

写错目标盘会覆盖其他磁盘——每一步都先确认设备编号。

MACOS

diskutil + dd

插入 SD 卡或让 CM4 eMMC 进入 mass-storage 模式后：

diskutil list
diskutil unmountDisk /dev/diskN
sudo dd if=tranquil-cm4.img \
  of=/dev/rdiskN bs=4m \
  status=progress conv=sync
sync && diskutil eject /dev/diskN
LINUX

lsblk + dd

写入整盘设备，不要写分区节点（如 sdX1）：

lsblk
sudo umount /dev/sdX*
sudo dd if=tranquil-cm4.img \
  of=/dev/sdX bs=4M \
  status=progress conv=fsync
sync
RPIBOOT

eMMC 直写

CM4 IO 底板设置 USB boot 跳线，USB slave 口连主机：

rpiboot
# eMMC 出现为块设备后，
# 按 macOS / Linux 步骤写入
# 完成后断电、移除跳线、上电

启动后验证这些项。

  • 串口日志：bootloader、hypervisor、kernel、SystemDaemon 依次就绪，capability root、调度器、IRQ/timer、服务注册均完成
  • 显示：virt 与 CM4 图形目标出现 800×480 系统画布
  • 服务：fsmgr、devmgr、windowmgr、appmgr 注册成功，launcher、settings、files 等应用可启动
  • 无法启动时：先查镜像完整性、是否写入整盘设备、CM4 boot 跳线与串口日志
